# 360RA 实时音量平衡

360RA 与普通立体声均支持音量平衡。首次播放不再预扫描整曲：正常解码同时读取 MPEG-H 固定双声道参考混音，使用 BS.1770 累计门控响度。该混音仅供测量，播放仍使用原对象与声床。

数据达到测量门槛后约每五秒更新一次全局增益，沿用平滑过渡；对象与声床比例保持不变。360RA 只衰减偏响节目，不根据量化参考的峰值放大安静节目。−18 LUFS 为软件对齐目标，不代表 Dolby 认证。

完整解码才保存整曲测量，下次用缓存固定增益起播。首次累计值会收敛，不能保证第一秒达到最终整曲目标。关闭开关旁路增益，测量仍随正常解码运行，没有第二个解码器或预扫描等待。

测试：实时参考与原整曲测量一致；开启参考采集前后的对象 PCM、元数据逐项一致；既有 BS.1770 与增益策略测试。
